# 📅 ระบบจองวันลาและตารางเวรออนไลน์ (ป้องกันจองซ้ำ 100%)

ระบบเว็บแอปพลิเคชันสำหรับอำนวยความสะดวกในการจัดคิวและลงทะเบียนจองสิทธิ์ลาปฏิบัติงานออนไลน์ ทำงานบนพื้นฐาน **Google Apps Script** ร่วมกับ **Google Sheets** และแจ้งรายงานทันทีผ่าน **Telegram Bot**

## 🌟 จุดเด่นของระบบ
- **Real-Time Choice Limit:** แถวที่เลือกแล้วจะอัปเดตสีและดึงออกจากระบบคัดกรองวันว่างทันทีแบบสดๆ
- **หมดปัญหาแย่งสิทธิ์:** ล็อกคิวประมวลผลด้วย `LockService` ของ Google Apps Script แม้กดส่งฟอร์มเสี้ยววินาทีเดียวกัน
- **แยกสีแถวชัดเจน:** แถวตารางจะคำนวณและแยกแสดงสีเพื่อให้ง่ายต่อการจำแนก (วันหยุด = แดง 🔴, จองลาแล้ว = น้ำเงิน 🔵, ว่าง = เขียว 🟢)
- **ระบบโทรคมนาคม:** ส่งแจ้งเตือนอัตโนมัติแจ้งชื่อผู้ลา, วันที่, ผู้ปฏิบัติงานแทน และเบอร์โทรศัพท์ติดต่อโดยทันที
